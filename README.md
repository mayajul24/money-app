# הכסף שלי

אפליקציית PWA אישית לניהול הוצאות והכנסות, שעונה על שאלה אחת: **כמה כסף אפשר לשים בצד בלי להסתכן במינוס**. React + Vite + TypeScript, אחסון מקומי בלבד (IndexedDB דרך Dexie) — אין שרת, אין ענן, הנתונים נשארים על המכשיר.

האפליקציה מתחילה ריקה לגמרי — מזינים משכורת, יתרה נוכחית והוצאות קבועות דרך ההגדרות, והתחזית משתפרת ככל שמצטברת היסטוריה.

## הרצה מקומית

1. `npm install`
2. `npm run dev`

## מבנה הפרויקט

- `src/lib/db.ts` - סכימת Dexie (IndexedDB): תנועות, הוצאות קבועות, פרופיל
- `src/lib/forecast.ts` - **מנוע התחזית** (פונקציות טהורות, בלי React) - מחשב תחזית סוף חודש והמלצת חיסכון בטוח/סביר/מסוכן
- `src/lib/insights.ts` - יצירת התובנות הטקסטואליות בדשבורד
- `src/lib/categories.ts` - רשימת הקטגוריות, צבעים ואייקונים
- `src/hooks/` - hooks ל-live query על תנועות, פרופיל, הוצאות קבועות, ותחזית מחושבת
- `src/components/` - מסכי Dashboard, תנועות, קטגוריות, היסטוריה, והגדרות

לוגיקת התחזית מופרדת לגמרי מה-UI ב-`forecast.ts`/`insights.ts` כדי שאפשר יהיה לשפר את האלגוריתם בלי לגעת בקומפוננטות.

## פריסה

מחובר ל-Vercel — כל push ל-`main` מפרסם אוטומטית.

## התקנה על הטלפון

פתחו את כתובת האתר בדפדפן הטלפון ובחרו "הוסף למסך הבית" (Add to Home Screen) כדי שתתנהג כמו אפליקציה רגילה, כולל עבודה אופליין.
